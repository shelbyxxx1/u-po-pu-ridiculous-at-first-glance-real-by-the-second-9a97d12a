# Ridiculous at First Glance, Real by the Second

Entry for the make.fun bounty
[Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a):
a program that writes one sentence to `/output/entry.txt` — a pitch for a
bizarre startup idea that sounds ridiculous at first glance but turns out
to be a real business.

## Run

```sh
python3 main.py
```

With no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.txt`
(the grader's mount). Standard library only, no network, no secrets.

## The pitch

> A mobile morgue-for-hire parks refrigerated autopsy suites outside
> hospitals during outbreaks, letting pathologists clear overflow bodies
> inside legal 48-hour limits so facilities dodge state fines.

One sentence, 198 characters — inside the gate's 1–200 characters.
